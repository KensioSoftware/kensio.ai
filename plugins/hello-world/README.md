# @kensio/hello-world

A minimal example skill that demonstrates the shape of a Kensio plugin. Install it
to verify that the marketplace is wired up correctly, then uninstall it.

```
/plugin marketplace add KensioSoftware/kensio.ai
/plugin install hello-world@kensio
```
